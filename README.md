# Husband Sorry Website ❤️

A playful static website built with HTML, CSS and JavaScript.

## Deploy with GitHub Pages

1. Create a new GitHub repository.
2. Upload all files from this folder.
3. Push them to the `main` branch.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, select **GitHub Actions**.
6. Push a change or manually run the **Deploy Husband Sorry Website** workflow.
7. GitHub will give you the Pages URL.

## Customize

Open `index.html` and change the messages if you want to make it more personal.

No backend or secrets are required.
